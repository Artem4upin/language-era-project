## Коротко о проекте

ActionScript - использовался для решения очень широкого круга задач, но почти всегда внутри среды Adobe Flash.
По сути, это был язык, позволяющий превращать flash-ролики в полноценные интерактивные приложения.
В 2000-х годах было модно делать «флеш-сайты» — полностью или частично построенные на Flash.
На ActionScript было создано огромное количество браузерных игр.
Долгое время Flash был стандартом для воспроизведения видео в интернете.
