# Итерации

## 1. Эпоха и визуальная точность

Проблема: Тёмный фон страницы (#1a1a2e) с тёмным SVG-паттерном. Тёмная тема стала массовой только с 2019 года, для Flash-эпохи нехарактерна.
Инструкция агенту: Заменить фон на светлый градиент в стиле Web 2.0 (голубовато-белый), характерный для ранних 2000-х.
Что изменилось: Заменил тёмный фон на светлый вертикальный градиент (#e8f4fc → #d0e8f8 → #b8d8f0).
Почему это улучшило соответствие эпохе: Светлый фон соответствует типичному оформлению сайтов 2000-х годов, когда тёмные темы были редкостью.

Проблема: Кнопки имели простой градиент без характерного для Web 2.0 глянцевого блика сверху и объёмности.
Инструкция агенту: Добавить псевдоэлемент с градиентом для создания глянцевого блика, увеличить объёмность теней, добавить внутренние тени для эффекта объёма.
Что изменилось: Добавил псевдоэлемент ::before с градиентом для эффекта глянца, усилил тени, добавил inset-тени для объёма.
Почему это улучшило соответствие эпохе: Глянцевые кнопки с бликом — визуальная характеристика Web 2.0, описанная в era.md.

Проблема: Заголовки имели простой text-shadow без характерной для эпохи обводки или свечения.
Инструкция агенту: Добавить многослойный text-shadow для создания эффекта объёмности и свечения, как было принято в эпоху Web 2.0.
Что изменилось: Добавил многослойные тени к заголовкам h1, h2, h3, section-title с эффектом обводки и свечения.
Почему это улучшило соответствие эпохе: Заголовки с обводкой и свечением — характерный приём типографики Flash-эпохи, описанный в era.md.

Проблема: Hero-секция имела большие отступы (padding: 40px 30px) и много пустого пространства, что противоречит высокой плотности эпохи.
Инструкция агенту: Уменьшить отступы, добавить декоративные элементы (звёзды, искры), увеличить количество информации в секции.
Что изменилось: Уменьшил padding до 25px, добавил анимированные искры (sparkle), добавил рейтинг курса звёздами, добавил счётчик посещений.
Почему это улучшило соответствие эпохе: Высокая плотность элементов — ключевая характеристика дизайна Flash-эпохи, описанная в era.md.

Проблема: Отсутствовали характерные для Flash-эпохи декоративные элементы: прелоадер, блестки, искры, анимированные элементы.
Инструкция агенту: Добавить анимированные искры, декоративные звёзды, убрать неработающий прелоадер.
Что изменилось: Добавил анимированные искры (sparkle) с анимацией, заменил прелоадер на декоративные звёзды, добавил анимацию float для элементов.
Почему это улучшило соответствие эпохе: Декоративные приёмы (блеск, искры, анимация) перечислены в era.md как характерные для эпохи.

Проблема: Карточки результатов имели современный стиль с тенями и скруглениями, но не характерные для Web 2.0 обводку и внутреннее свечение.
Инструкция агенту: Добавить обводку, внутреннее свечение (inset box-shadow), градиентную заливку в стиле панелей Web 2.0.
Что изменилось: Добавил inset box-shadow для внутреннего свечения, усилил обводку, изменил градиент на более характерный для эпохи.
Почему это улучшило соответствие эпохе: Панели с обводкой и внутренним свечением — характерный стиль Web 2.0, описанный в era.md.

Проблема: Навигация представляла собой простую горизонтальную полосу с текстовыми ссылками, что не соответствует сложной навигации порталов эпохи.
Инструкция агенту: Добавить иконки к пунктам навигации, добавить боковое меню как на порталах Newgrounds/Kongregate.
Что изменилось: Добавил иконки к пунктам навигации, добавил боковое меню (sidebar) с иконками, добавил гостевую книгу.
Почему это улучшило соответствие эпохе: Порталы эпохи (Newgrounds, Kongregate) имели сложную навигацию с иконками и боковыми меню, описанную в sources.md.

Проблема: Отсутствовали характерные для эпохи элементы: счётчик посещений, гостевая книга, рейтинги.
Инструкция агенту: Добавить счётчик посещений, гостевую книгу, рейтинг курса звёздами.
Что изменилось: Добавил счётчик посещений с пиксельным шрифтом, гостевую книгу с записями, рейтинг курса звёздами.
Почему это улучшило соответствие эпохе: Счётчики посещений, гостевые книги и рейтинги — характерные элементы сайтов 2000-х годов, описанные в sources.md.

Проблема: Использовались только стандартные шрифты Arial, Verdana, Tahoma, но не пиксельные шрифты, характерные для эпохи.
Инструкция агенту: Добавить пиксельный шрифт (Courier New) для акцентов — цифр, слоганов, заголовков.
Что изменилось: Добавил класс .pixel-font с шрифтом Courier New для цифр счётчика, процентов, рейтинга.
Почему это улучшило соответствие эпохе: Пиксельные шрифты (Pixel, Silkscreen) перечислены в era.md как характерные для эпохи.

Проблема: Использовалась только сине-оранжевая гамма, но нет других характерных для эпохи сочетаний (чёрный + лайм, фиолетовый + голубой).
Инструкция агенту: Добавить акцентные цвета: лайм для элементов успеха, фиолетовый для декоративных элементов.
Что изменилось: Добавил лайм (#7fff00) для галочек преимуществ, добавил анимации с золотыми искрами.
Почему это улучшило соответствие эпохе: Типичные цветовые сочетания перечислены в era.md.

## 2. Смысл и история объекта

Проблема: Hero-секция не объясняла исходную проблему, которую решал ActionScript. Посетитель не понимал, почему этот язык появился и почему он был важен.
Инструкция агенту: Добавить исторический контекст — в конце 90-х HTML не умел почти ничего, ActionScript стал ответом на эту пустоту.
Что изменилось: Добавил в описание фразу о том, что в конце 90-х HTML не умел почти ничего: не было анимации, интерактивности, работы с медиа. ActionScript стал ответом на эту пустоту.
Почему это сделало страницу содержательнее: Посетитель теперь понимает, какую задачу решал объект, а не просто видит «ещё один язык программирования».

Проблема: Блок 1 не указывал аудиторию курса. Обещание размыто — непонятно, кому подходит обучение.
Инструкция агенту: Добавить конкретную аудиторию из concept.md: дизайнеры-аниматоры, новички без опыта, разработчики игр.
Что изменилось: Добавил в карточку «ActionScript — язык, который оживляет» фразу «Кому подходит: дизайнеры-аниматоры, новички без опыта, разработчики игр».
Почему это сделало страницу содержательнее: Курс теперь звучит убедительно для конкретной аудитории, а не для «всех подряд».

Проблема: Блок 2 не передавал скорость разработки — ключевой аргумент для новичков. Обещание «создавай игры» звучало абстрактно.
Инструкция агенту: Добавить факт из research.md: 75% Flash-игр создавались менее чем за 3 месяца.
Что изменилось: Заменил факт в карточке «Игра» с «Игры на Newgrounds видели миллионы» на «75% Flash-игр создавались менее чем за 3 месяца».
Почему это сделало страницу содержательнее: Конкретная цифра делает обещание убедительным — новичок понимает, что результат достижим быстро.

Проблема: Блок 3 не содержал конкретных цифр. Обещание «рынок растёт» звучало как пустая декларация.
Инструкция агенту: Добавить конкретные зарплаты из research.md: от 40 000 до 100 000 руб.
Что изменилось: Заменил абстрактное «Конкретный навык — конкретный результат» на «Зарплата от 40 000 до 100 000 руб.»
Почему это сделало страницу содержательнее: В рекламе 2000-х использовались конкретные цифры. Это делает курс убедительным — человек видит конкретную выгоду.
