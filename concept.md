# Концепция

## Название вымышленных курсов

Разработка мультимедийных Flash-приложений на ActionScript

## Идея одним предложением

Курс, который учит превращать, через код на ActionScript,  Flash-ролик в интерактивное приложение, игру, сайт, плеер.

## Кто предлагает обучение

Учебный центр или онлайн-школа эпохи 2000-х.

## Аудитория

Дизайнеры-аниматоры, которые хотят перейти в программирование.
Новички без опыта, которым нужен быстрый вход в веб-разработку.
Разработчики, которые хотят делать игры и приложения для браузера.

## Главное обещание

Ты научишься писать на ActionScript и создашь собственное мультимедийное приложение, игру, сайт или плеер, которое увидят миллионы.

## Голос рекламы

Энтузиазм. «Ты сможешь. Это просто. Начни сейчас.»
Практичность. Конкретный навык - конкретный результат.
Серьёзность. Без иронии, без мемов, без самоиронии.
Срочность. Рынок растёт, конкуренты уже делают.

## Центральная шутка

Реклама той эпохти была прямой и серьёзной.

## Что посетитель должен понять об объекте

1. ActionScript — это язык, который оживляет Flash-ролик. Он управляет анимацией, реагирует на клики, создаёт игровую логику.
2. Flash — это среда, где дизайн и код живут в одном файле. Не нужно быть программистом с нуля — начинаешь с анимации, переходишь к коду.
3. Результат — приложение, которое работает везде. Один код для всех браузеров, для браузера и десктопа, для игры и сайта.

## Что агент не должен потерять при сборке

Связку «Flash + ActionScript» — они неразделимы, нельзя оставить только одно.
Эпоху — 1999–2010, не современность и не ретро-стилизация.
Практичность — курс обещает навык и результат, а не философию программирования.
Масштаб — Flash Player на 98% компьютеров, YouTube, ВКонтакте, игры.
Серьёзный тон — без иронии, мемов, самоиронии.
Визуальный язык — глянец, градиенты, плотность, движение, звук. Не плоский дизайн, не минимализм, не тёмная тема.
